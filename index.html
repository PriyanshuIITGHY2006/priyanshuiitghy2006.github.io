01
BDH-ECHR: Post-Transformer Interpretable Legal AI Jan – Feb 2026 Research Paper · Kriti 2026

Applied the Dragon Hatchling (BDH) post-transformer to multi-label ECHR legal violation classification. Achieved Micro-F1 = 0.7716, outperforming BERT-base by +13.2 pts and LegalBERT by +5.2 pts at 5.4× fewer parameters (20.4M vs. 110M). Conducted the first neuron→concept monosemanticity audit: 218 neurons mapped to 477 legal concepts; 2 neurons with perfect isolation (E=1.0); per-doc sparsity 0.305% — 16× below BDH's own target. Engineered hierarchical chunking with 7× BERT context window (3,584 tokens).

SpeakX Aurora — Self-Learning Notification Orchestrator Jan – Feb 2026 Kriti 2026 Hackathon

Domain-agnostic ML pipeline for behavioural segmentation and bilingual notification generation. 03
MemoryOS — Long-Form AI Memory System Feb 2026 NeuroHack 2026

Built for the NeuroHack Challenge (IITG.ai × Smallest.ai): a three-tier memory architecture that retains and recalls information across 1,000+ conversation turns. Layers: Buffer Memory (recent context), Core Memory (JSON + Vector DB), Archival Memory (ChromaDB). Implemented vector search with cosine similarity, entity deduplication, temporal boosting, and confidence score analytics dashboard. Tested to 1,500 turns with sub-200ms latency.

04
Minimum-Variance Portfolio Optimizer Dec 2025 – Present

Quantitative pipeline for the lowest-risk long-only portfolio from user-selected tickers. Applied Ledoit-Wolf shrinkage and nearest-PSD correction for covariance stability, preventing the optimizer from chasing ghost patterns. Custom data cleaning for multi-index yfinance structures. Enforced no-short-selling constraints with weight normalization. Demonstrates full Markowitz MPT pipeline from raw data to interpretable weights.

PythonPandasNumPyyfinancePyPortfolioOptMatplotlib

05
Kelly Criterion for Fixed-Limit Games Dec 2025 – Jan 2026 Mathematical Proof

Derived the Stochastic Gate — converting the optimal Kelly fraction f* into a Kelly Frequency for fixed-bet-size games (Finopoly, poker tournaments). Classical Kelly applies to sizing; this solves the Fixed-Limit constraint where sizing is fixed but frequency can be optimized. Built a Python stochastic decision engine matching the optimal geometric growth curve through mixed-strategy frequency. Co-developed with Md Adnan Khalid for the FEC, IITG recruitment challenge.
